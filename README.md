# programmesana-pamatkurss
F burts pirms pēdiņām ļauj teksta pēdiņās ievietot mainīgos lielumus vai izteiksmes - pythion automātiksi aizstāj mainīgo ar faktisko vērtību.
Commit ziņai ie jābūt konkrētai, lai saprastu veiktās izmaiņas, nepieciešamības gadījumā atrastu un iznamtotu vecāku koda versiju. (Piemēram, lai vieglāk salabotu jauno kļūdu)

Izpildot Termināļa komandrindu "python uzdevumi/diena1.py" programma palaidās.

Viens un tas pats ceļs Termināļa komandrindā dažreiz nedarbojas, jo tas meklē informāciju atbilstoši jau pašreizējai direktorijai, konkrētajā situācijā - atrodoties mapē, tas meklē vēl vienu mapi ar tādu pašu nosaukumu, tomēr tā neeksistē.

.gitignore fails saglabā informāciju par failu nosaukumiem, kurus nav nepieciešams sinhronizēt ar mākoņa serveri. (saglabāt lietošanai tikai lokāli)
